# Temporal contingency selection

A contigency in lines 39-47 is selected and used in the temporal-spatial experiment.

[pw_contigency_analysis.csv](pw_contigency_analysis.csv) contains the PowerWorld contingency-analysis
results used to select the fixed network contingency for the temporal-spatial
experiment.

The contingency analysis was performed on the Glover 37-bus benchmark before
the temporal short-circuit-level results were evaluated.

The selected contingency was the outage of line 39–47, circuit 1.

## Selection procedure

The line with most violations was selected.
